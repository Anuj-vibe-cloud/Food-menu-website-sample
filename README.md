# Gourmet Blaze - Luxury Food Menu Website

A responsive, professional, and visually rich 3D-style food menu website for the luxury restaurant brand Gourmet Blaze. Built with HTML5, CSS3, and vanilla JavaScript.

## Key Features

*   **Visually Appealing Design:** Modern dark theme with orange accents and glowing effects.
*   **Hero Section:** Full-page hero image/gradient with an animated headline.
*   **Sticky Navbar:** Smooth scrolling navigation that sticks to the top.
*   **3D-style Menu Cards:** Interactive menu cards with hover effects (lift, scale, shadow changes).
*   **Categorized Menu:** Sections for Starters, Main Course, Desserts, and Beverages.
*   **Responsive Design:** Adapts to various screen sizes (desktops, tablets, and mobile phones).
*   **Smooth Scrolling:** JavaScript-powered smooth scrolling for anchor links.
*   **Placeholder Content:** Uses Unsplash for dynamic placeholder images for menu items.
*   **Clean Code:** Well-commented HTML, CSS, and JavaScript for maintainability.

## How to View

1.  Clone this repository or download the files.
2.  Open the `index.html` file in your preferred web browser.

Alternatively, if deployed (e.g., to GitHub Pages), access the provided URL.

## Project Structure

-   `index.html`: The main HTML file containing the website structure.
-   `css/style.css`: The stylesheet for all visual styling.
-   `js/script.js`: JavaScript for interactive features like smooth scrolling.
-   `assets/`: Folder for static assets (currently empty as images are hotlinked).
-   `README.md`: This file.
